USB Guardian｜使用須知、風險揭露與使用條款
文件版本：V3.2 RC（2026-11-18）

本文件適用於 USB Guardian V3.2 候選版。請完整閱讀，尤其是「可能發生的資料損失」及「本工具做不到的事」。USB Guardian 是用來提醒、檢視並協助判斷 USB 裝置與檔案的輔助工具，不是防毒保證、資料保全服務或能攔截所有硬體攻擊的產品。本文件以易於理解、明確揭露風險為原則；任何條款均不得排除法律禁止排除的責任。

一、軟體功能與適用範圍
1. 本工具在程式啟動並持續運作時，觀察 Windows 回報的 USB、裝置及磁碟事件，依設定顯示通知、事件記錄與有限的風險提示。
2. 可由使用者選擇外接或可攜式磁碟，查看部分目錄、檔名、大小與屬性。快速檢查範圍有限，不是全碟掃描，也不會完整解析所有檔案。
3. 對雙重副檔名、執行檔、捷徑等特徵顯示提醒。這些特徵可能出現在正常檔案；沒有警告也不表示檔案安全。
4. SafeLab 使用 Windows AppContainer 限權程序，為部分文字、圖片與檔案中繼資訊提供預覽；不執行未知程式、巨集、腳本。AppContainer 不是完整虛擬機，不能保證解析漏洞不存在。
5. 使用者可以另行選擇 Microsoft Defender 掃描、檔案隔離、還原或適用裝置的停用／重新啟用。這些功能彼此獨立，不能把「預覽成功」「掃描指令完成」當作「已通過安全驗證」。

二、必須知道的 USB 安全限制
1. USB Guardian 在裝置被 Windows 偵測後才可能收到事件；惡意鍵盤、網路轉接器或其他複合裝置，可能在通知顯示前已經運作。軟體不能保證「掃描前零操作、零聯網、零資料存取」。
2. USB 裝置名稱、廠商與產品識別碼、PnP 識別資訊可以被模仿，不能當作不可偽造的身分證明。「熟悉／信任」僅是使用者的本機紀錄，並非安全認證。
3. 沒有發現問題、沒有出現通知、SafeLab 完成預覽，或 Defender 命令結束，都不能保證沒有惡意程式、隱藏韌體攻擊或資料外洩。
4. 請勿因為本軟體存在，就將不明 USB 插入存有重要資料的電腦；也不要在主系統執行來源不明的 EXE、LNK、巨集或腳本。

三、掃描與第三方安全服務
1. 選擇 Defender 掃描會交由 Windows／Microsoft Defender 執行，該服務可能依其設定偵測、隔離、刪除或上傳可疑樣本；操作及資料處理由 Microsoft 的產品設定和政策決定。
2. 本工具可能顯示「已送出掃描」「命令完成」「狀態待確認」等結果；它不自行保證掃描範圍完整，也不提供惡意程式鑑定或威脅清除承諾。
3. 若 Windows 安全性顯示威脅，請以 Windows 安全性中的實際偵測結果為準，並確認是否需要備份或尋求專業協助。

四、隔離檔案、還原及永久刪除的風險
1. 隔離必須由使用者在完成預覽後主動選擇；黃色檔名警示不會自動導致隔離。支援範圍有限：Windows 標示為 Removable 的磁碟、符合條件的普通檔案，大小上限約 24 MiB。
2. 隔離會嘗試驗證來源、建立加密副本與紀錄，成功後再嘗試從 USB 移除原檔。拔除裝置、斷電、磁碟錯誤、被其他程序改寫或程式崩潰，都可能使隔離未完成、原檔未移除或副本無法還原。
3. 隔離資料與密鑰儲存在目前 Windows 使用者的本機資料夾，使用 DPAPI 保護密鑰及 AES-GCM 加密。這能降低部分風險，但不代表能抵抗同帳戶惡意程式、帳戶被入侵或所有資料損毀。
4. 還原時必須連回原裝置及可寫入的目標資料夾；如果路徑改變、原目錄不存在、已有同名檔案或使用者帳戶變更，就可能無法還原。
5. 「永久移除隔離副本」在本程式內不可撤銷，且不代表底層儲存媒體已完成符合鑑識標準的安全抹除。請先另行備份重要資料。

五、Windows 裝置停用與復原的風險
1. 「標記不信任」僅修改本機紀錄，不會實際切斷硬體、封鎖網路或停止檔案存取。
2. 系統停用只限能由 Windows 證據明確定位、且符合 USBSTOR 儲存介面安全條件的裝置，並需使用者確認及 Windows 管理員授權；本工具不提供對鍵盤、滑鼠、集線器、一般 HID 或網路卡的自動停用。
3. 停用時若有寫入、備份、程式使用該磁碟，可能造成檔案損毀、工作中斷或資料遺失。請在操作前停止讀寫、保存工作及備份。
4. 命令成功不必然代表裝置已無法使用；本工具會嘗試重新查詢 Windows 狀態。停用可能需要重新插拔、重開機或透過裝置管理員處理；恢復功能也可能因系統狀態而失敗。
5. 本工具不提供 USB 插入前的全功能預設拒絕政策，也不保證同一個裝置的其他介面一併停用。

六、使用者應採取的基本防護措施
1. 定期備份重要資料，維持 Windows 與 Defender 更新，並限制不可信裝置與檔案在重要電腦上的使用。
2. 在隔離、永久刪除、停用硬體或還原前，應確認磁碟代號、裝置來源、路徑及將影響的檔案。對不清楚的項目，請選擇取消並尋求協助。
3. 不應使用本軟體管理他人設備或資料，除非已取得所有人及適當管理員的授權。
4. 不要用含有唯一副本的重要資料的 USB 進行測試；如需練習，請使用可清除的測試磁碟與非惡意的測試檔。

七、資料隱私與本機保存
1. USB Guardian 的基本檢視功能不要求註冊帳戶；程式設計上不主動將預覽內容傳送至 USB Guardian 的遠端伺服器。Windows、Defender、使用者啟用的同步／備份程式可能另有資料傳送行為。
2. 程式可能在目前使用者的 LocalAppData 保留裝置名稱或識別摘要、事件時間、通知已讀狀態、偏好設定、同意紀錄、隔離檔案與加密金鑰資料。檔名、磁碟代號與事件記錄可能包含個人或機敏資訊。
3. 手動匯出或分享報告前，請檢查可能包含的裝置名稱、路徑、檔名及操作歷史。使用者自行決定分享對象。
4. 解除安裝應用程式不一定會自動刪除本機 AppData；若需清除，請先確認已還原或備份隔離檔案及重要記錄，避免不可逆的損失。

八、效能、相容性與更新
1. 本工具在 Windows 10／11 的受支援環境中使用；不同版本、驅動程式、權限或硬體可能使部分功能失效。Windows Home 和 Pro 的政策能力不一定相同。
2. 監控與檔案檢查會使用 CPU、記憶體及磁碟存取；本工具不保證零資源消耗、零延遲、無錯誤或不中斷服務。
3. 本工具不保證持續更新、提供即時客服、與所有第三方工具相容，或在每一台 Windows 電腦都可使用。公開發布前應檢查目前版本與已知問題。
